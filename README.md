# Johan Rehn — Portfolio Website

A personal portfolio website designed and developed to showcase my skills, projects, and experience in web development and graphic design.

The website combines a clean, modern visual identity with responsive layouts, interactive navigation, project case studies, and dedicated sections for both development and design work.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and minimal visual design
- Responsive navigation with mobile menu
- Home page with personal introduction
- About page with personal profile and development journey
- Work page showcasing selected projects
- Dedicated project case studies
- Graphic design portfolio section
- Contact page with contact information and links
- Image galleries for project presentations
- Responsive project layouts
- Smooth hover and transition effects
- Semantic HTML structure
- Custom CSS styling without external CSS frameworks

🎨 Design Approach

The goal of the portfolio was to create a website that feels personal, professional, and visually consistent while keeping the interface easy to navigate.

The design uses a dark visual foundation combined with subtle contrast, typography, spacing, and image-focused project presentations.

Rather than relying on a pre-built template, the website was developed with custom HTML, CSS, and JavaScript to give me full control over the layout and visual identity.

📱 Responsive Design

The website is designed to work across different screen sizes.

Desktop
Laptop

Mobile

Navigation, typography, spacing, grids, project layouts, and image galleries adapt depending on the available screen width.

🚀 Getting Started

To run the project locally, clone the repository:

git clone https://github.com/Klockrehn/Portfolio.git

Navigate into the project directory:

cd Portfolio

Then open index.html in your browser.

No build process or package installation is required.
